# Ward Jobs

Android ward jobs list: patients by ward/bed/initials, jobs with priority, timestamps and progress notes, locked long-term follow-ups (e.g. send-away bloods), handover as text/PDF, and list sharing between phones as a file.

Data stays on the phone (no server, no cloud backup). Built with Vite + React + Capacitor; GitHub Actions builds a signed APK and publishes it as a release, which the app installs as an update (needs the `APP_GH_TOKEN` secret).
